# TalentLens Studio — 2026 Interactive Hiring Decision Cockpit

High-impact, zero-fluff interactive cockpit created for **Catalina Gil Sierra** (Lead TA & Psychometric Systems Architect).

- **Module 1: Interview ➔ Weighted Fit % Converter & BARS Arena**
- **Module 2: Bad-Hire P&L Bleed Simulator (SHRM/HBR Methodology)**

## Tech Stack
- **Vite 6** + **React 19** + **TypeScript**
- **Tailwind CSS v4** + **OKLCH Wide-Gamut Color Space**
- **Geist & Geist Mono** Typography (Variable Fonts bundled)
- **Web Audio API** Synthesized Tactile Sound Effects

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Deploy the resulting `dist/` directory to **Cloudflare Pages** or any modern edge hosting.
